# k-means

# K-Means Clustering & Machine Learning Portfolio

This repository contains practical machine learning notebooks and datasets focusing on unsupervised learning (**K-Means Clustering**) and supervised learning (**Decision Trees**), implemented in Python.

---

## 📂 Repository Contents

### **1. Jupyter Notebooks**
* [`Activity_Build a K-means model.ipynb`](https://github.com/dyyland23-glitch/k-means/blob/main/Activity_Build%20a%20K-means%20model.ipynb): Walkthrough and implementation of an unsupervised K-means clustering model.
* [`Activity_Build a decision tree.ipynb`](https://github.com/dyyland23-glitch/k-means/blob/main/Activity_Build%20a%20decision%20tree.ipynb): Practical activity for building and evaluating a decision tree classifier.
* [`Annotated follow-along guide_ Build a decision tree with Python.ipynb`](https://github.com/dyyland23-glitch/k-means/blob/main/Annotated%20follow-along%20guide_%20Build%20a%20decision%20tree%20with%20Python.ipynb): Step-by-step guidance for constructing decision trees.
* [`Annotated follow-along guide_ Tune and validate decision trees with Python.ipynb`](https://github.com/dyyland23-glitch/k-means/blob/main/Annotated%20follow-along%20guide_%20Tune%20and%20validate%20decision%20trees%20with%20Python.ipynb): Advanced guide covering hyperparameter tuning and model validation techniques.

### **2. Datasets (`.csv`)**
* [`Invistico_Airline.csv`](https://github.com/dyyland23-glitch/k-means/blob/main/Invistico_Airline.csv): Passenger satisfaction survey dataset used for classification tasks.
* [`penguins.csv`](https://github.com/dyyland23-glitch/k-means/blob/main/penguins.csv): Palmer Penguins dataset used for clustering and classification analysis.
